# BoG

An online card game you play with friends in the browser.

## Play it on your computer

1. Install [Node.js](https://nodejs.org) (the "LTS" version).
2. In this folder, run `npm install` once.
3. Run `npm start` and open http://localhost:3000.
4. Click **Make a room** and send the 4-letter code to your friends.

## Files

- `server.js` runs the game and keeps track of rooms.
- `public/` is the web page players see.
